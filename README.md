# Algoritmia y Estructura de Datos | 1INF27 - PUCP
Repositorio dedicado a la recopilación de evaluaciones y soluciones del curso Algoritmia y Estructura de Datos (1INF27) de la Pontificia Universidad Católica del Perú (PUCP), correspondientes a los ciclos académicos desde 2023-2 en adelante.

El contenido está desarrollado principalmente en C++ y tiene como finalidad servir como material de consulta, práctica y reforzamiento para los estudiantes del curso.

## 📝 Evaluaciones

Este repositorio está destinado a recopilar evaluaciones de diferentes ciclos académicos:

- 🧪 **Laboratorios:** Ejercicios prácticos de implementación de algoritmos y estructuras de datos.
- 📘 **Exámenes parciales:** Evaluaciones correspondientes a la primera parte del curso.
- 📕 **Exámenes finales:** Evaluaciones integrales de los temas desarrollados durante el ciclo.

Las evaluaciones se irán incorporando progresivamente y estarán organizadas por ciclo académico.
